## How to launch the app

Run from the `min_app` folder with Node.js and npm installed:

```bash
npm install
npm start
```

On mobile, scan the QR code with Expo Go compatible with Expo SDK 57. Keep your phone and computer on the same Wi-Fi.

To open in a browser instead:

```bash
npm run web
```

Open the localhost URL shown in the terminal.
